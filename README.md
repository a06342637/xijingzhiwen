# 栖境 Qijing

Windows 多环境浏览器管理软件。管理界面使用 Electron / React / TypeScript，网页在独立的 Chromix（Chromium）或 Camoufox（Firefox）中打开。本地单用户使用，不包含网站自动化、脚本任务、定时任务或 AI 操作。

[下载最新版本](https://github.com/a06342637/xijingzhiwen/releases/latest) · [验证报告](VERIFICATION.md) · [修复记录](BUGFIXES.md) · [第三方许可证](THIRD_PARTY_NOTICES.md)

## 安装与开始使用

1. 下载对应电脑架构的安装包：Windows ARM64 使用 `Qijing-0.1.13-arm64-Setup.exe`，常见 Intel/AMD 电脑使用 `Qijing-0.1.13-x64-Setup.exe`。未配置代码签名证书。
2. 在“内核管理”下载 Chromix 或 Firefox / Camoufox，或导入完整本地内核目录中的可执行文件。软件安装包不包含浏览器内核；诊断 Python 组件也按需下载。
3. 新建环境，选择引擎、系统/设备、内核、硬件参数与代理，保存后点击“启动环境”。网页由用户自己操作。
4. 每个环境有独立数据目录和登录数据。配置修改关闭后保存，重新启动生效。复制只复制配置，生成新种子，不复制 Cookie 或本地存储。

| 电脑类型 | 安装包选择 |
| --- | --- |
| Intel/AMD 处理器的 Windows 10/11 电脑 | `Qijing-0.1.13-x64-Setup.exe` |
| 骁龙等 ARM 处理器的 Windows 10/11 电脑 | `Qijing-0.1.13-arm64-Setup.exe` |
| Apple M 系列或 Intel 芯片的 Mac，运行 macOS | 暂无 macOS 安装包，不能安装 Windows `.exe` |
| Linux 电脑 | 暂无 Linux 安装包 |

Windows 可在“设置 → 系统 → 关于 → 系统类型”查看：基于 x64 的处理器选 x64，基于 ARM 的处理器选 ARM64。Apple 芯片属于 ARM，但 Windows ARM64 包不能用于 macOS。软件内的 macOS/Linux 选项仅模拟浏览器身份。普通用户只下载 `Setup.exe`，`.yml`、`.blockmap` 和校验清单不用安装。

Chromix 候选基线 `155.0.8059.79`；Firefox 候选 `158.0.1-beta.41`（Camoufox 测试版）。下载核对 SHA-256、Windows PE 架构和许可证文件；没有校验信息不启用。软件与内核分开更新，环境固定绑定具体内核版本。

## 默认启动的环境检测总览

打开环境时默认展示本地总览页，通过同一浏览器环境和代理访问 Who（1ms.dog）、BrowserLeaks、Sannysoft、CreepJS。检测使用临时标签页，逐站采集后关闭；不额外启动浏览器窗口。自定义启动网址作为额外标签页，只有 `about:blank` 时不再增加空标签。

- 顶部显示检测站看到的真实 IP、地区、运营商，以及网页实际语言和时区；启动查询的出口单独保留，出口变化或时区差异明确提示。Who 不可用时可从 BrowserLeaks IP 页补充出口并标注来源。
- Who 展示原站等级、分数和扣分建议；其他站显示 DNS 解析器、WebRTC 地址、通过项目或特征比例。它们没有统一官方总分，不拼出一个虚构的安全分数。
- 点击「刷新检测」重新采集，清除旧出口、等级和结果；每站有时限，网络失败、HTTP 错误、部分结果与通过分开显示。高级本地观测有 12 秒时限，保留基础信息并提示未完成；旧采样不会覆盖新结果。可展开详情、打开原站、导出当前 JSON 报告，原站打开失败会提示原因。离开总览网址停止本轮采集，返回后可重新开始；关闭总览释放本地服务，其他用户标签保留。
- 「软件设置 → 启动环境检测总览 → 默认打开」可关闭；关闭后仅按环境自己的启动网址打开。内部环境诊断不自动触发此页。
- 检测站会收到当前出口 IP 与浏览器特征；数据保存在本次本地服务内，除主动导出不另作历史记录。每次刷新重新访问站点，可能有流量开销和供应商 IP 轮换。站点结构改变、挑战页或无法访问时会受限，不绕过验证码。
- 总览中文使用本地开源界面字体，不修改第三方网站的字体白名单。报告随实际内核/架构记录，检测结果不证明匿名或绝对安全。

## 引擎、系统与设备边界

| 环境 | 支持方式与限制 |
| --- | --- |
| Windows 软件 | 提供 ARM64/x64 安装包；无 macOS/Linux 原生安装包 |
| Windows/macOS/Linux 电脑身份 | 两种引擎中的展示预设，不替换真实宿主系统、字体栅格器或硬件 |
| Firefox | Camoufox Windows 仅 x64，ARM64 电脑使用兼容运行；不接入 Chromix 实测设备、Canvas 固定种子、音频隔离或 Chromium 扩展目录 |
| iPhone/iPad/Android | Chromium 的布局、屏幕、方向、DPR、触摸、UA/Client Hints 模拟；不是真实 Safari/WebKit 或移动系统 |
| 屏幕 | 13 组移动尺寸样本和 1366×768 至 5120×2880 电脑尺寸，包含 2K/4K/5K/超宽屏；CSS/DIP 单位，可自定义 |

只有部分特性在特定内核与硬件实测通过，不承诺所有网站识别、真机等价或防关联效果。诊断页只用于核对固定配置，不提供用户脚本执行入口。每次使用独立地址并校验来源；用户在检查期间离开该页后，清理不会强制改变新页面。

## CPU / 显卡与一键随机

硬件选择在“新建环境”和“软件设置 → 新建环境的默认指纹”中。支持 NVIDIA GTX/RTX 20–50、AMD Radeon RX 500/6000/7000/9000、Intel UHD/Iris/Arc A/B、Ryzen、Core/Core Ultra、AMD 集显与 Apple M 的常见样本。不是全部市场型号清单，也不是完整原生设备采集。

- CPU 名称仅在软件中记录；网页主要读取 `navigator.hardwareConcurrency` 的逻辑处理器数，不是物理核心数，也不改变指令集和真实性能。
- Client Hints CPU 架构仍由内核和宿主决定；ARM 电脑选择 Intel/AMD 型号不会变成 x86。ARM 上运行 x64 内核也可能返回 arm，环境诊断附带此项实际值。
- 组合内存 4–256GB 整数为记录（常见 16/32/64GB），自定义非标准值会映射到支持的浏览器内存值，`deviceMemory` 为离散/限幅浏览器值（常见为 8）；火狐没有该 API。
- 显卡配置修改 WebGL Vendor/Renderer 名称，不能替换真实显卡、驱动、算力、GL 扩展、像素或 WebGPU。原生软件渲染/不可用上下文可能不覆盖名称。
- 组合按系统筛选，不随机现代 RTX 到 macOS，Intel/AMD 集显不跨 CPU 平台。单选 CPU/GPU 会保留本次选择，只调整不兼容的另一侧。
- 一键/批量随机默认“一致性优先”：保持内核品牌、原生 GPU，无触摸电脑布局，窗口留在工作区内；默认不自动增加 Canvas/音频扰动，明确选过的策略会保留。可切换“随机硬件组合”使用型号库；硬件随机关闭保留手选配置，移动模拟保持自身配置。旧环境原随机策略保留，需手动选择推荐策略。
- 手动修改线程数或 WebGL 参数会清除旧型号记录；自定义组合明确显示，不误标为原生 GPU。

手动 UA 可能与 Client Hints 不一致。切换引擎会清除上一引擎的手动 UA 和版本；已有环境不能直接跨引擎改写登录目录，请新建。

## 代理与语言时区

新建环境默认不绑定代理，选择“本地网络 · 直连”；浏览器启动显式不继承系统代理。需要代理时在创建页选择“手动填写 / 粘贴代理”，一次粘贴完整信息即可。默认自动识别 `hostname:port:username:password`，也支持 `用户名:密码@主机:端口` 等五种格式及 HTTP/HTTPS/SOCKS5 URL。歧义格式需要选定格式后解析；协议不随凭据猜测，未带协议使用当前选定协议。

新环境默认打开“按代理出口匹配语言与时区”：有代理时在启动前查询实际出口，覆盖手动语言和时区；关闭开关后使用手动值。直连不查询，查询失败中止启动；已有环境保留自己的配置。同一代理并发保存按顺序写入，保存期间不能删除或退出/安装更新，避免旧密码覆盖新密码。多时区国家依据启动时的出口城市，轮换代理后续 IP 变化可能导致不一致，建议供应商提供固定会话。

代理默认限制非代理 UDP；Chromium 禁用 QUIC 并限制目的域名本地解析；Firefox 启用远端 SOCKS DNS、关闭预取和直连回退。本地诊断走回环。手动绕过和放宽 WebRTC 策略会改变路由限制。网关域名仍需由本机解析以建立连接。

此前 CA 代理测试未出现同样的本机直连 DNS，STUN 检查未返回可见 ICE 地址；供应商 DNS 跨地区、出口轮换，不能保证加拿大 DNS、所有流量走代理或所有网站无泄露。WebRTC 地址展示也不等于通信路由。

本轮 BrowserLeaks 完整 DNS 测试：US 代理返回 48 个解析器（含德国），CA 代理返回 72 个（含日本/墨西哥/德国等）；直连只返回 3 个本机出口所在新加坡的解析器。未观察到相同的本机直连 DNS，但不能把这些代理称为无泄漏或安全。代理 TCP 特征被识别为 Android、直连为 Windows，属于服务端可见网络路径；需要供应商提供固定会话、匹配地区的 DNS/出口和原生 TCP 路径。仅启用浏览器 DoH 的临时对照未消除代理 DNS 跨国，未默认启用无效方案。

“测试出口”连续通过代理查询三次 IP/时区，提示出口轮换和时区漂移；其中一次失败即报错，不回退直连。三次一致只是当前样本，不保证其他网站同一出口。2026-11-02 用户提供的 CA/US 节点在检测页的公网 IP 分别识别加拿大/美国；两条节点都观察到多个出口和不同时区。自动匹配只能绑定启动时查询值，需供应商固定会话或固定城市解决后续漂移。

推荐策略且自动出口匹配开启时，英文 CA/US Windows 电脑会在启动时使用英文 Windows 字体名单；手动限制名单不覆盖，关闭匹配后使用手动配置。当前生效值会附在诊断报告，不改写保存配置。英文 CA/US 电脑也可在“高级配置 → 字体 / 存储”点击“使用英文 Windows 字体名单”。只限制真实字体族，不修改系统；中文及其他文字回退可能受限，可手动编辑或恢复原生。随机保留所选字体策略和名单。实测后 US 页面的中文系统推断消失、综合推断转为美国；这是网站启发式结果，不证明真机等价。

0.1.11 补充修复火狐跨站导航丢失深浅色配置。检测页的延迟项比较实际资源请求耗时与服务器 TCP RTT；仅伪造 `navigator.connection.rtt` 不会消除这段真实延迟。固定种子保证同一环境稳定，因此不保证通过“每次读回都变化”的评分。直接开启火狐 `resistFingerprinting` 实测会把时区改成 UTC 并覆盖屏幕/显卡，不作为默认多环境配置。

## 默认设置、更新与数据

默认指纹只用于新建，已有环境保留自己的参数。保存默认预设期间暂时锁定编辑，完成后恢复，避免未保存修改被标记为成功。随机及保存期间编辑区暂时锁定，模式切换会重选匹配引擎的内核并清理旧设备记录。每次批量最多 100 个环境，独立种子和目录；多个环境应留空下载路径使用各自目录。

启动后默认检查 GitHub 并下载对应架构新版，SHA-512 通过后提示“安装并重启”。可关闭自动检查，手动点击“检查更新”。安装前正常关闭环境，准备期间出错取消此次安装；不会在用户工作中直接重启。0.1.1 及更早版本需手动安装一次。

2026-11-02 在线更新专项实测通过：两种架构从 GitHub 下载 0.1.9 并通过 SHA-512；ARM64 隔离安装从 0.1.2 升到 0.1.9，自动重启另行实测通过，升级后安装版能读取保留的环境和更新设置，检查更新返回当前已是最新版本。本轮没有执行 x64 原生在线安装。新增重启参数回归后，75 项本地测试与生产构建通过。

在线更新/覆盖安装保留配置与环境；主动卸载清除软件数据目录和更新缓存，用户自选外部下载目录不清除。删除单个环境会把浏览器目录移到数据目录 `trash`，下载文件保留。内核升级通过数据副本检查，原环境保留。复制只使用新目标，已有目标、原目录或原目录内的路径会拒绝；复制失败只清理本次创建的目录。

日志位于数据目录 `logs/software-update.log`，不依赖终端。不要公开代理密码、Cookie、完整环境目录或个人诊断数据。

## 验证与已知限制

0.1.12 本轮：91 项测试、TypeScript/生产构建、多检测站、默认直连/整条代理解析/推荐随机/自动字体匹配及隔离界面回归通过；Cookie、扩展、代理认证、两引擎桌面和代表移动环境证据保留；具体证据与发布状态见 [VERIFICATION.md](VERIFICATION.md)。

本机 Windows ARM64 的 Chromium 图形上下文受限，相关 WebGL/WebGPU 不标“已验证”，没有绕过 GPU blocklist。火狐代表组合 WebGL 1 名称曾实测匹配，但不证明完整 GPU 或像素能力一致。原生 x64 GPU 全量检查仍需对应硬件，不能用构建通过代替。

实测设备记录遵守上游摘要、宿主、模式及时效校验。字体、媒体、Widevine、实验项受平台/内核限制；Widevine 不分发。Canvas Bridge 需要自备服务并可能影响沙箱。SOCKS5 UDP、完整 ClientRects 扰动、完整虚拟 GPU、跨机器原生 Cookie 数据库不属于当前交付能力。

## 开发和发布

```powershell
npm ci
node node_modules/electron/install.js
npm test
npm run build
npm run smoke
npm run pack
```

`npm run smoke` 使用隔离测试数据。可设置 `QIJING_SMOKE_BROWSER=1`、`QIJING_SMOKE_FLOWS=1`、`QIJING_SMOKE_RACES=1`、`QIJING_SMOKE_UPGRADE=1`、`QIJING_SMOKE_RELIABILITY_UI=1`、`QIJING_SMOKE_DEEP_UI=1`、`QIJING_SMOKE_HARDWARE_UI=1`、`QIJING_SMOKE_HARDWARE=1`、`QIJING_SMOKE_DEVICE_UI=1`；`QIJING_SMOKE_DEVICES=1` 配合 `QIJING_SMOKE_DEVICE_MATRIX=1` 验证 13 组设备横竖屏。报告/截图在 `.verification/`，也可用 `QIJING_SMOKE_OUTPUT` 选择本次输出；不上传用户数据。

源码目录 `C:\Users\adminuser\Downloads\xijingzhiwen`；产物目录相邻 `xijing发行版本/<版本号>`。上游固定提交与诊断组件摘要位于 `resources/upstream.json`、`resources/components.json`，第三方许可证保留在安装资源及 `dist/licenses/`。

后续更新修改版本号、release notes、README 和验证报告，提交 main 并推送 `vX.Y.Z`。GitHub Actions 分别构建/检查 ARM64 与 x64，生成独立 `latest-arm64.yml` / `latest.yml`；`scripts/publish.mjs` 完整上传校验草稿后公开，不覆盖已发布二进制。
