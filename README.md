# 栖境 Qijing

Windows 多环境浏览器管理软件。管理界面使用 Electron / React / TypeScript，网页在独立的 Chromix（Chromium）或 Camoufox（Firefox）中打开。本地单用户使用，不包含网站自动化、脚本任务、定时任务或 AI 操作。

[下载最新版本](https://github.com/a06342637/xijingzhiwen/releases/latest) · [验证报告](VERIFICATION.md) · [修复记录](BUGFIXES.md) · [第三方许可证](THIRD_PARTY_NOTICES.md)

## 安装与开始使用

1. 下载对应电脑架构的安装包：Windows ARM64 使用 `Qijing-0.1.21-arm64-Setup.exe`，常见 Intel/AMD 电脑使用 `Qijing-0.1.21-x64-Setup.exe`。未配置代码签名证书。
2. 在“内核管理”下载 Chromix 或 Firefox / Camoufox，或导入完整本地内核目录中的可执行文件。软件安装包不包含浏览器内核；诊断 Python 组件也按需下载。
3. 新建环境，选择引擎、系统/设备、内核与硬件参数；默认可粘贴代理，留空直连。启动网址默认留空，不添加额外页面；保存后点击“启动环境”。首页开关仍独立控制，网页由用户自己操作。
4. 每个环境有独立数据目录和登录数据。配置修改关闭后保存，重新启动生效。复制只复制配置，生成新种子，不复制 Cookie 或本地存储。

环境列表在状态后显示「创建时间」「启动时间」，按本机时区展示日期和时分秒。启动时间只在浏览器确认启动成功后更新，进入已运行窗口不会改动；没有启动记录显示「从未」。创建/复制/批量新建的环境不继承其他环境的启动时间，旧版回收站恢复保留原时间；旧版没有记录的历史启动无法补推。

「随机指纹」同时填写随机名称，再次点击会更换；单个环境可在随机后手动改名。批量创建每个名称和指纹独立随机，代理保持不变。

「指纹平铺」位于新建环境按钮前。默认继承环境列表中勾选的已打开窗口，未勾选时列出并选择全部可用窗口；可在面板重新勾选，切换窗口列表/表格展示，选自动、左右、上下或网格排列，设置显示器、网格列数及间距并预览。自动排列1–4个左右均分，更多自动分行；使用桌面可用工作区避开任务栏，只调整栖境启动且当前虚拟桌面可见的浏览器主窗口。最小化窗口平铺时恢复，未选窗口不动。固定页面视口保持配置，过多窗口受浏览器最小尺寸限制可能重叠。

普通环境地址栏默认使用 Google 搜索，输入 `chatgpt` 等文字进入搜索；完整网址仍直接访问。Chromium首次启动通过原生搜索设置添加/选择Google，之后保留用户自行更换的选择；Firefox修复内核自带的「None」搜索策略，原策略备份保留。访问Google需要当前网络/代理可连接Google。

| 电脑类型 | 安装包选择 |
| --- | --- |
| Intel/AMD 处理器的 Windows 10/11 电脑 | `Qijing-0.1.21-x64-Setup.exe` |
| 骁龙等 ARM 处理器的 Windows 10/11 电脑 | `Qijing-0.1.21-arm64-Setup.exe` |
| Apple M 系列或 Intel 芯片的 Mac，运行 macOS | 暂无 macOS 安装包，不能安装 Windows `.exe` |
| Linux 电脑 | 暂无 Linux 安装包 |

Windows 可在“设置 → 系统 → 关于 → 系统类型”查看：基于 x64 的处理器选 x64，基于 ARM 的处理器选 ARM64。Apple 芯片属于 ARM，但 Windows ARM64 包不能用于 macOS。软件内的 macOS/Linux 选项仅模拟浏览器身份。普通用户只下载 `Setup.exe`，`.yml`、`.blockmap` 和校验清单不用安装。

Chromix 候选基线 `155.0.8059.79`；Firefox 候选 `158.0.1-beta.41`（Camoufox 测试版）。下载核对 SHA-256、Windows PE 架构和许可证文件；没有校验信息不启用。软件与内核分开更新，环境固定绑定具体内核版本。

## 默认启动的环境首页

打开环境默认展示本地中文首页，只通过当前浏览器、代理和指纹请求出口 JSON 信息，不再后台运行详细检测站。顶部显示真实 IP、中文地区、运营商、浏览器语言及中文时区；启动查询出口与当前查询出口分开显示，出口轮换/时区差异提示保留。未收录的地点中文译名显示未收录，原始值可悬停查看和导出，不编造译名。

- Who、BrowserLeaks、Sannysoft、CreepJS、Whoer 显示为网站图标，点击在当前环境打开检测站，由用户操作。首页不再展示各站的详细分数/项目，不自动采集检测成绩。
- 「刷新信息」重新查询当前出口及本地浏览器信息；高级 API 观测有 12 秒时限，旧采样不覆盖新结果。支持导出当前信息、网络失败提示和打开站点失败提示。
- 软件设置可分别关闭「启动环境检测总览」和「首页检测网站入口」。关闭首页后只打开环境配置的网址；关闭检测入口后隐藏图标并禁止本地打开命令。内部环境诊断不自动打开首页。
- 网站仅在点击后取得检测特征；首页出口查询也会把当前 IP 和 UA 发往 Who 的 JSON 接口，代理可能按请求切换出口。结果保存在本次本地服务，主动导出才保存报告。
- 环境列表为默认展示方式，已有安装在首次应用新设置时改为列表；之后手动切换卡片/列表都会保存。环境数据、种子及登录数据不因此改变。

## 新建环境编辑界面

弹窗打开回到顶部，不自动聚焦下面的名称框。随机工具下方依次排列紧凑代理、创建数量和基本资料，再展示浏览器引擎/设备/硬件。代理输入只保留整条文本和测试状态，不展开名称、协议、主机、端口、用户名、密码、绕过规则或解析按钮；输入自动识别，无法唯一识别时使用带协议的 URL 格式。原绕过规则在编辑中保留。已保存代理使用不含密码的文字显示；同一用户名下修改主机而未输入新密码时保留原认证，显式更改/移除认证则以新文本为准。

## 随机书签与默认扩展

软件设置的「随机默认书签」默认开启，每个环境从15,000个域名抽取60个并散排在书签栏。首次或缓存过期时通过该环境代理读取首页标题，直连环境使用本地网络；不运行这些网页脚本。标题成功缓存七天，失败一天后重试，获取失败先显示域名。正常打开书签网站首页时也记录当前标题，下次启动更新；关闭后移除软件生成项，保留手动书签。

扩展管理在「导入扩展目录」旁提供设置按钮。新导入扩展默认开启，可逐个开关；总开关开启时新建 Chromium 环境默认勾选已开启扩展，也可在创建时取消选择。已有环境的扩展配置保留；旧版导入的扩展需要手动开启，Firefox/实测设备模式不继承 Chromium 扩展。

底部操作提示统一在 10 秒后隐藏，收到新提示重新计时。下载进度、失败详情与验证报告持续保留。

## 内核下载与诊断组件

「一键下载所有」按顺序下载两个引擎当前可用列表中的版本与架构（各源最近 15 个发行条目），跳过已安装/正在下载项；失败记录后继续下一项。单项下载仍可并行，摘要和架构校验保留。下载全部版本可能占用较多磁盘空间。

Python 嵌入包按需下载 Windows C++ 运行库及架构匹配的 DLL，保留依赖许可证；不要求用户手动安装 Python。原生扩展、运行库与初始化文件纳入完整性记录。图形验证和设备采集使用正确工具导入路径；修复 DLL 缺失不等于全部图形项目通过。

「已验证」是报告注明条件下检查通过；「受限」是功能可用但受内核/硬件限制；「未验证」是尚无完整通过记录，不代表一定失效；「不支持」是当前模式没有该能力。状态可悬停查看说明，原生 WebGL 不可用会说明硬件条件不足。

## 环境选择、删除与回收站

工具栏和列表表头都能全选当前搜索/分组/筛选下的环境。「清除选择」后方提供「删除勾选」；正在运行、启动或数据操作中的环境拒绝删除，批量操作分别显示成功/失败。

删除不再弹确认窗，立即从列表移到回收站。环境配置、固定种子、软件管理的独立浏览器及下载数据一起保留三天；回收站入口在搜索/视图按钮旁，显示删除时间和到期时间，可恢复或立即彻底删除。到期按软件运行时的定时检查清理，软件关闭期间不会运行，下一次打开清理已到期记录。

彻底删除移除该环境的回收数据、配置记录及其软件管理的报告数据；不删除外部自定义下载文件夹，也不删除其他环境共用代理、内核或扩展。回收中的环境保留依赖引用，避免恢复后丢失内核；恢复不覆盖已存在目录。旧版本无配置备份的保留目录不会被当作新回收站记录自动删除或虚构恢复。

环境列表的网络列显示最后实测的代理国家/IP与测试时间，而不是网关域名的地区；可就地测试或打开独立代理编辑弹窗。编辑只影响当前环境，共用代理自动另存；运行时须先关闭，保存时锁定环境，种子与指纹配置不改变。路由字段改变会清除旧检测记录，重新测试后更新。平台/浏览器列展示 Windows/macOS/Linux 或移动模拟，以及谷歌内核/火狐。

## CPU / 显卡与一键随机

硬件选择在“新建环境”和“软件设置 → 新建环境的默认指纹”中。支持 NVIDIA GTX/RTX 20–50、AMD Radeon RX 500/6000/7000/9000、Intel UHD/Iris/Arc A/B、Ryzen、Core/Core Ultra、AMD 集显与 Apple M 的常见样本。不是全部市场型号清单，也不是完整原生设备采集。

- CPU 名称仅在软件中记录；网页主要读取 `navigator.hardwareConcurrency` 的逻辑处理器数，不是物理核心数，也不改变指令集和真实性能。
- Client Hints CPU 架构仍由内核和宿主决定；ARM 电脑选择 Intel/AMD 型号不会变成 x86。ARM 上运行 x64 内核也可能返回 arm，环境诊断附带此项实际值。
- 组合内存 4–256GB 整数为记录（常见 16/32/64GB），自定义非标准值会映射到支持的浏览器内存值，`deviceMemory` 为离散/限幅浏览器值（常见为 8）；火狐没有该 API。
- 显卡配置修改 WebGL Vendor/Renderer 名称，不能替换真实显卡、驱动、算力、GL 扩展、像素或 WebGPU。原生软件渲染/不可用上下文可能不覆盖名称。
- 组合按系统筛选，不随机现代 RTX 到 macOS，Intel/AMD 集显不跨 CPU 平台。单选 CPU/GPU 会保留本次选择，只调整不兼容的另一侧。
- 点击“一键随机指纹”随机名称及未固定的指纹字段，代理、引擎和设备类型保持。设置里修改的预设自动勾选“随机时保留”，可逐项取消或全部解除；旧预设按与初始值的差异迁移。单次/批量随机均保留固定值及其必要的兼容参数，已有环境使用自身的固定值，不被后来修改的默认值重写。随机默认使用系统字体，避免中文/日文/韩文字形缺失。
- 广泛随机保留代理出口匹配/WebRTC 网络策略，开启出口匹配后语言/时区由实际出口覆盖；手动 UA 不生成冲突字符串，版本跟随所绑内核。真实 IP、外部目录、扩展和实验服务不凭空生成，实验/降低沙箱配置保持关闭。更大随机度不保证检测分数更高或匿名。
- 手动修改线程数或 WebGL 参数会清除旧型号记录；自定义组合明确显示，不误标为原生 GPU。

手动 UA 可能与 Client Hints 不一致。切换引擎会清除上一引擎的手动 UA 和版本；已有环境不能直接跨引擎改写登录目录，请新建。

## 代理与语言时区

新建环境的代理输入默认“手动填写 / 粘贴代理”，留空仍不绑定代理，浏览器显式不继承系统代理。粘贴完整信息自动解析；字段填充完整后延时查询实际出口，也可以点击“测试当前代理”。展示实测国家、地区、城市、运营商、IP、时区和测试时间；测试失败不能视为通过。默认自动识别 `hostname:port:username:password`，也支持 `用户名:密码@主机:端口` 等五种格式及 HTTP/HTTPS/SOCKS5 URL。歧义格式需要选定格式后解析；协议不随凭据猜测，未带协议使用当前选定协议。

新环境默认打开“按代理出口匹配语言与时区”：有代理时在启动前查询实际出口，覆盖手动语言和时区；关闭开关后使用手动值。直连不查询，查询失败中止启动；已有环境保留自己的配置。同一代理并发保存按顺序写入，保存期间不能删除或退出/安装更新，避免旧密码覆盖新密码。多时区国家依据启动时的出口城市，轮换代理后续 IP 变化可能导致不一致，建议供应商提供固定会话。

代理默认限制非代理 UDP；Chromium 禁用 QUIC 并限制目的域名本地解析；Firefox 启用远端 SOCKS DNS、关闭预取和直连回退。本地诊断走回环。手动绕过和放宽 WebRTC 策略会改变路由限制。网关域名仍需由本机解析以建立连接。

此前 CA 代理测试未出现同样的本机直连 DNS，STUN 检查未返回可见 ICE 地址；供应商 DNS 跨地区、出口轮换，不能保证加拿大 DNS、所有流量走代理或所有网站无泄露。WebRTC 地址展示也不等于通信路由。

本轮 BrowserLeaks 完整 DNS 测试：US 代理返回 48 个解析器（含德国），CA 代理返回 72 个（含日本/墨西哥/德国等）；直连只返回 3 个本机出口所在新加坡的解析器。未观察到相同的本机直连 DNS，但不能把这些代理称为无泄漏或安全。代理 TCP 特征被识别为 Android、直连为 Windows，属于服务端可见网络路径；需要供应商提供固定会话、匹配地区的 DNS/出口和原生 TCP 路径。仅启用浏览器 DoH 的临时对照未消除代理 DNS 跨国，未默认启用无效方案。

“测试出口”连续通过代理查询三次 IP/时区，提示出口轮换和时区漂移；其中一次失败即报错，不回退直连。三次一致只是当前样本，不保证其他网站同一出口。2026-11-02 用户提供的 CA/US 节点在检测页的公网 IP 分别识别加拿大/美国；两条节点都观察到多个出口和不同时区。自动匹配只能绑定启动时查询值，需供应商固定会话或固定城市解决后续漂移。

自动出口匹配只填未固定的语言和时区，固定预设优先。字体名单包含本机可用的中文、日文、韩文和泰文字体回退；旧版广泛随机产生的窄名单在启动时恢复原生，不改写保存配置。手动固定名单不会被覆盖，名单中没有可用字形时仍可能显示方框；可恢复原生字体。

0.1.11 补充修复火狐跨站导航丢失深浅色配置。检测页的延迟项比较实际资源请求耗时与服务器 TCP RTT；仅伪造 `navigator.connection.rtt` 不会消除这段真实延迟。固定种子保证同一环境稳定，因此不保证通过“每次读回都变化”的评分。直接开启火狐 `resistFingerprinting` 实测会把时区改成 UTC 并覆盖屏幕/显卡，不作为默认多环境配置。

## 默认设置、更新与数据

默认指纹只用于新建，已有环境保留自己的参数。保存默认预设期间暂时锁定编辑，完成后恢复，避免未保存修改被标记为成功。随机及保存期间编辑区暂时锁定，模式切换会重选匹配引擎的内核并清理旧设备记录。每次批量最多 100 个环境，独立种子和目录；多个环境应留空下载路径使用各自目录。

启动后默认检查 GitHub 并下载对应架构新版，SHA-512 通过后提示“安装并重启”。可关闭自动检查，手动点击“检查更新”。安装前正常关闭环境，准备期间出错取消此次安装；不会在用户工作中直接重启。0.1.1 及更早版本需手动安装一次。

2026-11-02 在线更新专项实测通过：两种架构从 GitHub 下载 0.1.9 并通过 SHA-512；ARM64 隔离安装从 0.1.2 升到 0.1.9，自动重启另行实测通过，升级后安装版能读取保留的环境和更新设置，检查更新返回当前已是最新版本。本轮没有执行 x64 原生在线安装。新增重启参数回归后，75 项本地测试与生产构建通过。

在线更新/覆盖安装保留配置与环境；主动卸载清除软件数据目录和更新缓存，用户自选外部下载目录不清除。删除单个环境会把浏览器目录移到数据目录 `trash`，下载文件保留。内核升级通过数据副本检查，原环境保留。复制只使用新目标，已有目标、原目录或原目录内的路径会拒绝；复制失败只清理本次创建的目录。

日志位于数据目录 `logs/software-update.log`，不依赖终端。不要公开代理密码、Cookie、完整环境目录或个人诊断数据。
