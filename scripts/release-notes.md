栖境 0.1.6

- 加入 50 个 CPU、63 个 GPU 型号和 49 套常见组合，涵盖 NVIDIA RTX/GTX、AMD Radeon/Ryzen、Intel Core/Ultra/Arc 与 Apple M。
- 新建与默认设置支持搜索、品牌筛选、整机组合、CPU/显卡单选和内存记录。
- 一键/批量随机按系统选择硬件组合；关闭硬件随机时保留手选参数。
- 不将现代 RTX 配给 macOS，不把 Intel/AMD 集显配给不同 CPU 平台；引擎切换同步 WebGL 名称格式。
- CPU 型号与物理内存为软件记录，网页可见线程数和 WebGL 名称按内核设置。不会替换真实 GPU、算力或 WebGPU；受限结果见环境诊断。
- 复查 Chromium、火狐创建、启停、设备预设、Cookie、下载、扩展和代理认证。环境与登录数据在在线更新后保留。
