栖境 0.1.13

## 先看这里：你的电脑下载哪个？

| 你的电脑 | 应下载的安装包 |
| --- | --- |
| Windows 10/11，Intel 酷睿或 AMD 锐龙等常见电脑 | **Qijing-0.1.13-x64-Setup.exe** |
| Windows 10/11 ARM 电脑，例如骁龙 Snapdragon、Surface Pro X | **Qijing-0.1.13-arm64-Setup.exe** |
| 苹果 Mac，M1/M2/M3/M4 等 Apple 芯片 | **目前没有 macOS 安装包，不能使用上面的 Windows .exe** |
| 苹果 Mac，Intel 芯片，正在运行 macOS | **目前没有 macOS 安装包** |
| Linux 电脑 | **目前没有 Linux 安装包** |

Windows 不确定架构：打开“设置 → 系统 → 关于 → 系统类型”。显示“基于 x64 的处理器”选 x64；显示“基于 ARM 的处理器”选 ARM64。

**软件中的 Windows / macOS / Linux 是浏览器身份模拟选项，不代表提供这些系统的原生软件。Apple 芯片同样使用 ARM 架构，但 Windows ARM64 安装包不能安装到 macOS。**

普通用户只下载对应的 **Setup.exe**。`.yml` 和 `.blockmap` 是软件在线更新用的文件，`SHA256SUMS` 是校验清单，都不用安装。浏览器内核在软件内按需下载。

## 本版更新

- **环境启动默认显示检测总览**：真实 IP、地区、运营商、浏览器语言/时区、启动出口变化提示。
- 同一环境临时标签采集 Who 真实等级/分数/建议、BrowserLeaks DNS/WebRTC、Sannysoft 检查和 CreepJS 比例；采集后关闭，不增加另一个浏览器窗口。
- 支持刷新、详情、原站查看、JSON 报告；超时、网络失败和部分结果如实显示，不生成虚构安全分。
- 「软件设置 → 启动环境检测总览」可关闭，环境启动网址保留；内部诊断不触发检测。默认检测会访问第三方站点并暴露当前出口和特征。
- 英文字体限制下总览中文使用独立 OFL 界面字体，不更改外站指纹；更新保留环境数据，浏览器内核仍按需下载。

第三方站点结果只代表该次观察，不保证匿名、全部满分或全部网站兼容。Mac/Linux 暂无原生安装包。
