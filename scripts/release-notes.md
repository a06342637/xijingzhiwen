栖境 0.1.27

## 先看这里：你的电脑下载哪个？

| 你的电脑 | 应下载的安装包 |
| --- | --- |
| Windows 10/11，Intel 酷睿或 AMD 锐龙等常见电脑 | **Qijing-0.1.27-x64-Setup.exe** |
| Windows 10/11 ARM 电脑，例如骁龙 Snapdragon、Surface Pro X | **Qijing-0.1.27-arm64-Setup.exe** |
| 苹果 Mac，M1/M2/M3/M4 等 Apple 芯片 | **目前没有 macOS 安装包，不能使用上面的 Windows .exe** |
| 苹果 Mac，Intel 芯片，正在运行 macOS | **目前没有 macOS 安装包** |
| Linux 电脑 | **目前没有 Linux 安装包** |

Windows 不确定架构：打开“设置 → 系统 → 关于 → 系统类型”。显示“基于 x64 的处理器”选 x64；显示“基于 ARM 的处理器”选 ARM64。

**软件中的 Windows / macOS / Linux 是浏览器身份模拟选项，不代表提供这些系统的原生软件。Apple 芯片同样使用 ARM 架构，但 Windows ARM64 安装包不能安装到 macOS。**

普通用户只下载对应的 **Setup.exe**。`.yml` 和 `.blockmap` 是软件在线更新用的文件，`SHA256SUMS` 是校验清单，都不用安装。浏览器内核在软件内按需下载。

## 本版更新

- **平铺并启动**：批量启动旁新增入口，等所选环境启动完成后自动平铺到当前显示器；已运行环境保留，失败环境单独提示。
- **Firefox批量启动**：最多4个并行准备，代理出口查询与配置/worker加载并行；浏览器启动后异步准备首页，不让首页观测拖住整批启动。仍遵守软件设置运行上限。
- **平铺页面尺寸修复**：桌面平铺清除固定页面视口，页面随实际窗口内容区域调整；修复Chromium临时会话恢复旧视口、Firefox固定外窗口尺寸干扰平铺和最大化窗口恢复问题。环境已保存指纹配置保留，移动布局仍保持专用设置。
- **代理管理独立列表**：只显示在代理管理手动保存的节点，环境粘贴/批量/API代理仅用于环境，不混入列表。原环境绑定保留，手动库代理不会因删除环境被自动清理。
- **验证**：162项测试、构建、17项管理界面和真实四Firefox启动平铺、两引擎再次排列/书签/代理切换回归通过。

未签名Windows ARM64/x64安装包，浏览器内核按需下载，在线升级保留环境和登录数据；暂无macOS/Linux原生安装包。
