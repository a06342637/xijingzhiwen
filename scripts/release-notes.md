栖境 0.1.14

## 先看这里：你的电脑下载哪个？

| 你的电脑 | 应下载的安装包 |
| --- | --- |
| Windows 10/11，Intel 酷睿或 AMD 锐龙等常见电脑 | **Qijing-0.1.14-x64-Setup.exe** |
| Windows 10/11 ARM 电脑，例如骁龙 Snapdragon、Surface Pro X | **Qijing-0.1.14-arm64-Setup.exe** |
| 苹果 Mac，M1/M2/M3/M4 等 Apple 芯片 | **目前没有 macOS 安装包，不能使用上面的 Windows .exe** |
| 苹果 Mac，Intel 芯片，正在运行 macOS | **目前没有 macOS 安装包** |
| Linux 电脑 | **目前没有 Linux 安装包** |

Windows 不确定架构：打开“设置 → 系统 → 关于 → 系统类型”。显示“基于 x64 的处理器”选 x64；显示“基于 ARM 的处理器”选 ARM64。

**软件中的 Windows / macOS / Linux 是浏览器身份模拟选项，不代表提供这些系统的原生软件。Apple 芯片同样使用 ARM 架构，但 Windows ARM64 安装包不能安装到 macOS。**

普通用户只下载对应的 **Setup.exe**。`.yml` 和 `.blockmap` 是软件在线更新用的文件，`SHA256SUMS` 是校验清单，都不用安装。浏览器内核在软件内按需下载。

## 本版更新

- **全选、删除勾选和三天回收站**：删除无需确认弹窗，配置、固定种子、独立浏览器及软件管理的下载数据可恢复；显示删除/到期时间，可立即彻底删除。软件关闭期间到期项目下次启动清理。
- **代理粘贴后自动测试**：默认粘贴模式，空输入直连；显示真实国家、城市、运营商、IP、时区和测试时间，可手动重测。环境列表网络列展示实测国家/IP，提供独立代理测试/编辑按钮，平台列显示系统和谷歌内核/火狐。
- **中文环境首页和手动检测图标**：不再自动采集详细网站评分，只有出口 JSON 查询；Who、BrowserLeaks、Sannysoft、CreepJS、Whoer 点击后自行检测。首页和检测入口分别开关，启动网址默认留空不添加额外页。
- **内核并行下载**：不同内核/架构可以同时下载，相同项目防重复，摘要与架构校验保留。
- **修复 Python 诊断组件**：按需校验下载 Windows C++ 运行库，修复 greenlet DLL 缺失和设备采集工具导入路径；两种架构原生自检、设备采集通过。原生 WebGL 不可用等硬件限制明确解释。
- **默认列表、验证状态说明、JP/TH 字体匹配**：手动参数保留，独立代理保存不影响共用代理环境；旧采样/超时和失败提示完善。
- 软件更新保留现有环境、登录数据与内核。浏览器内核、Python 和运行库按需下载，不在安装包内。

## 使用边界

回收只处理软件管理的目录，外部自定义下载文件夹及共用代理/内核/扩展保留。运行中的环境须先关闭再删除/修改代理。回收中的环境仍占用依赖，需恢复或彻底删除后才可移除依赖。

代理网关地域不等于出口国家；IP 轮换、境外解析器、真实网络延迟和 HTTP 代理不支持 UDP/HTTP3 不是改 UA 就能解决。实测亚洲网关 TH2 某次 Who A，不代表所有节点、后续连接或网站均通过。固定身份可能被再次识别。

未签名 Windows 安装包。暂无 macOS/Linux 原生安装包，iPhone/iPad/Android 仅浏览器身份与布局模拟。检测结果不保证匿名、满分或所有网站兼容。
