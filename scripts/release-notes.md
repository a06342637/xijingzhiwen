栖境 0.1.16

## 先看这里：你的电脑下载哪个？

| 你的电脑 | 应下载的安装包 |
| --- | --- |
| Windows 10/11，Intel 酷睿或 AMD 锐龙等常见电脑 | **Qijing-0.1.16-x64-Setup.exe** |
| Windows 10/11 ARM 电脑，例如骁龙 Snapdragon、Surface Pro X | **Qijing-0.1.16-arm64-Setup.exe** |
| 苹果 Mac，M1/M2/M3/M4 等 Apple 芯片 | **目前没有 macOS 安装包，不能使用上面的 Windows .exe** |
| 苹果 Mac，Intel 芯片，正在运行 macOS | **目前没有 macOS 安装包** |
| Linux 电脑 | **目前没有 Linux 安装包** |

Windows 不确定架构：打开“设置 → 系统 → 关于 → 系统类型”。显示“基于 x64 的处理器”选 x64；显示“基于 ARM 的处理器”选 ARM64。

**软件中的 Windows / macOS / Linux 是浏览器身份模拟选项，不代表提供这些系统的原生软件。Apple 芯片同样使用 ARM 架构，但 Windows ARM64 安装包不能安装到 macOS。**

普通用户只下载对应的 **Setup.exe**。`.yml` 和 `.blockmap` 是软件在线更新用的文件，`SHA256SUMS` 是校验清单，都不用安装。浏览器内核在软件内按需下载。

## 本版更新

- 随机默认书签：软件设置可开关，15,000 个公开域名中每个环境随机抽取 60 个并打乱，创建/复制/重新随机各自独立，重启保留；关闭后下次启动移除专用文件夹，保留用户书签。
- 扩展默认加载：导入旁设置按钮、扩展逐个开关；开启后新建 Chromium 环境继承已开启扩展，已有环境保持原选择，Firefox 不加载 Chromium 扩展。
- 内核「一键下载所有」：当前列出的两个引擎发行版本与架构逐个排队，已安装跳过，失败后继续；单项并行下载保留。
- 底部提示 10 秒自动隐藏，重复提示重新计时；下载和错误详情持续可查。
- 书签不会自动访问网站。域名排名不代表安全或可访问，也不保证指纹检测评分；浏览器内核仍按需下载，在线升级保留已有环境数据。
