栖境 0.1.20

## 先看这里：你的电脑下载哪个？

| 你的电脑 | 应下载的安装包 |
| --- | --- |
| Windows 10/11，Intel 酷睿或 AMD 锐龙等常见电脑 | **Qijing-0.1.20-x64-Setup.exe** |
| Windows 10/11 ARM 电脑，例如骁龙 Snapdragon、Surface Pro X | **Qijing-0.1.20-arm64-Setup.exe** |
| 苹果 Mac，M1/M2/M3/M4 等 Apple 芯片 | **目前没有 macOS 安装包，不能使用上面的 Windows .exe** |
| 苹果 Mac，Intel 芯片，正在运行 macOS | **目前没有 macOS 安装包** |
| Linux 电脑 | **目前没有 Linux 安装包** |

Windows 不确定架构：打开“设置 → 系统 → 关于 → 系统类型”。显示“基于 x64 的处理器”选 x64；显示“基于 ARM 的处理器”选 ARM64。

**软件中的 Windows / macOS / Linux 是浏览器身份模拟选项，不代表提供这些系统的原生软件。Apple 芯片同样使用 ARM 架构，但 Windows ARM64 安装包不能安装到 macOS。**

普通用户只下载对应的 **Setup.exe**。`.yml` 和 `.blockmap` 是软件在线更新用的文件，`SHA256SUMS` 是校验清单，都不用安装。浏览器内核在软件内按需下载。

## 本版更新

- **书签散排**：60 个随机书签直接显示在书签栏，不再放进带环境名的文件夹。标题为英文用途和域名；未知用途标注未核实。旧版本自动迁移，保留手动添加的书签。
- **修复文字方框**：复现旧版窄字体名单导致中文缺失的问题。随机默认使用系统字体，旧自动名单在启动时修正；Windows 字体预设增加多语言回退。
- **预设优先**：设置里修改的字段自动固定，3070、东八区等在单次随机和批量创建中保留；未固定字段继续随机。支持解除固定，已有环境保留自身值。
- 自动代理出口匹配保留固定语言/时区及字体配置；随机名称、平铺、Google 搜索、扩展和更新功能继续可用。
- 132 项回归测试、隔离界面操作和真实 Chromium/Firefox 书签/多语言显示检查通过。

未签名Windows ARM64/x64安装包，浏览器内核按需下载，在线升级保留环境和登录数据；暂无macOS/Linux原生安装包。
