栖境 0.1.26

## 先看这里：你的电脑下载哪个？

| 你的电脑 | 应下载的安装包 |
| --- | --- |
| Windows 10/11，Intel 酷睿或 AMD 锐龙等常见电脑 | **Qijing-0.1.26-x64-Setup.exe** |
| Windows 10/11 ARM 电脑，例如骁龙 Snapdragon、Surface Pro X | **Qijing-0.1.26-arm64-Setup.exe** |
| 苹果 Mac，M1/M2/M3/M4 等 Apple 芯片 | **目前没有 macOS 安装包，不能使用上面的 Windows .exe** |
| 苹果 Mac，Intel 芯片，正在运行 macOS | **目前没有 macOS 安装包** |
| Linux 电脑 | **目前没有 Linux 安装包** |

Windows 不确定架构：打开“设置 → 系统 → 关于 → 系统类型”。显示“基于 x64 的处理器”选 x64；显示“基于 ARM 的处理器”选 ARM64。

**软件中的 Windows / macOS / Linux 是浏览器身份模拟选项，不代表提供这些系统的原生软件。Apple 芯片同样使用 ARM 架构，但 Windows ARM64 安装包不能安装到 macOS。**

普通用户只下载对应的 **Setup.exe**。`.yml` 和 `.blockmap` 是软件在线更新用的文件，`SHA256SUMS` 是校验清单，都不用安装。浏览器内核在软件内按需下载。

## 本版更新

- **启动提速**：新Firefox环境在正式启动时恢复原生书签备份，移除一次后台初始化浏览器；准备代理、扩展、书签与搜索设置并行执行。批量启动最多同时准备3个，仍遵守软件并发上限。
- **平铺提速**：复用窗口管理进程与已编译代码，筛选目标浏览器进程；提前准备窗口服务，异步调整不逐窗抢焦点。每次仍核对环境目录、进程和窗口，跳过关闭的环境。
- **校验与修复**：本次软件会话内复用未变化内核的SHA-256校验，文件身份/大小/修改时间变化即重新核验；修复并发启动共用扩展处理竞争。书签预设、用户书签和已有浏览器数据保持。
- **本机测量**：Firefox新环境约57秒→9.3秒，重复平铺约2.9秒→0.25秒，重复窗口读取约1.7秒→0.15秒。Chromium首次约4.5秒→3.0秒；重复启动变化不大。结果为本机Windows ARM64隔离条件，其他电脑/代理/扩展耗时不同。
- **验证**：157项测试、构建、15项管理界面及真实Chromium/Firefox书签、窗口和代理切换隔离回归通过。

未签名Windows ARM64/x64安装包，浏览器内核按需下载，在线升级保留环境和登录数据；暂无macOS/Linux原生安装包。
