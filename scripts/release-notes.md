栖境 0.1.18

## 先看这里：你的电脑下载哪个？

| 你的电脑 | 应下载的安装包 |
| --- | --- |
| Windows 10/11，Intel 酷睿或 AMD 锐龙等常见电脑 | **Qijing-0.1.18-x64-Setup.exe** |
| Windows 10/11 ARM 电脑，例如骁龙 Snapdragon、Surface Pro X | **Qijing-0.1.18-arm64-Setup.exe** |
| 苹果 Mac，M1/M2/M3/M4 等 Apple 芯片 | **目前没有 macOS 安装包，不能使用上面的 Windows .exe** |
| 苹果 Mac，Intel 芯片，正在运行 macOS | **目前没有 macOS 安装包** |
| Linux 电脑 | **目前没有 Linux 安装包** |

Windows 不确定架构：打开“设置 → 系统 → 关于 → 系统类型”。显示“基于 x64 的处理器”选 x64；显示“基于 ARM 的处理器”选 ARM64。

**软件中的 Windows / macOS / Linux 是浏览器身份模拟选项，不代表提供这些系统的原生软件。Apple 芯片同样使用 ARM 架构，但 Windows ARM64 安装包不能安装到 macOS。**

普通用户只下载对应的 **Setup.exe**。`.yml` 和 `.blockmap` 是软件在线更新用的文件，`SHA256SUMS` 是校验清单，都不用安装。浏览器内核在软件内按需下载。

## 本版更新

- 环境列表在「状态」后增加「创建时间」与「启动时间」两列，显示日期和时分秒。
- 启动时间记录最后一次实际成功启动；从未启动或旧版没有启动记录时显示「从未」。进入已运行浏览器不会更新，启动失败不新增记录。
- 时间保存到本机数据库，软件重启及回收恢复保留；复制、批量新建和升级副本不会继承原环境启动时间。编辑环境保留真实记录。
- 123项测试通过，保留Google默认搜索、随机书签、默认扩展、下载队列和10秒提示。

在线升级保留环境与登录数据。未签名Windows ARM64/x64安装包，浏览器内核按需下载，暂无macOS/Linux原生安装包。
