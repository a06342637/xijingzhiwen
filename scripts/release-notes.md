栖境 0.1.23

## 先看这里：你的电脑下载哪个？

| 你的电脑 | 应下载的安装包 |
| --- | --- |
| Windows 10/11，Intel 酷睿或 AMD 锐龙等常见电脑 | **Qijing-0.1.23-x64-Setup.exe** |
| Windows 10/11 ARM 电脑，例如骁龙 Snapdragon、Surface Pro X | **Qijing-0.1.23-arm64-Setup.exe** |
| 苹果 Mac，M1/M2/M3/M4 等 Apple 芯片 | **目前没有 macOS 安装包，不能使用上面的 Windows .exe** |
| 苹果 Mac，Intel 芯片，正在运行 macOS | **目前没有 macOS 安装包** |
| Linux 电脑 | **目前没有 Linux 安装包** |

Windows 不确定架构：打开“设置 → 系统 → 关于 → 系统类型”。显示“基于 x64 的处理器”选 x64；显示“基于 ARM 的处理器”选 ARM64。

**软件中的 Windows / macOS / Linux 是浏览器身份模拟选项，不代表提供这些系统的原生软件。Apple 芯片同样使用 ARM 架构，但 Windows ARM64 安装包不能安装到 macOS。**

普通用户只下载对应的 **Setup.exe**。`.yml` 和 `.blockmap` 是软件在线更新用的文件，`SHA256SUMS` 是校验清单，都不用安装。浏览器内核在软件内按需下载。

## 本版更新

- **统一功能开关**：手动 UA/版本、硬件覆盖、图形/音频扰动、输入/显示/时钟、字体/媒体限制、实验功能、原生对照和移动布局集中到“软件设置 → 浏览器行为与测试功能”，首次升级与新安装默认全部关闭。开启必须在设置里二次确认，取消不保存。
- **启动权限检查**：旧环境配置、单次随机、批量创建与代理自动匹配不能绕过关闭的功能。已有环境保留原配置，关闭功能后下次启动停止应用；更改开关前需关闭已运行环境。代理、语言、时区、窗口和本地书签功能保留。
- **移动布局一致性**：移除伪装 Safari/Android 的 UA、平台和 Client Hints；仅保留主动开启的屏幕/触摸布局测试，使用实际 Chromium 身份。移动布局与原生对照可能报告 webdriver=true，开启提示中明确说明。
- **原生硬件与设置响应**：关闭硬件/输入覆盖后不再传入默认假定线程数、内存与输入参数；设置刷新合并诊断组件重复校验，使用组件前仍完整重验。
- **验证**：144项测试、22项管理界面回归及9组本地浏览器跨作用域检查；覆盖旧配置、Windows/macOS/Linux、移动布局、原生对照和Firefox。普通桌面主页面/iframe的webdriver为false，UA/平台/线程数/时区与Worker一致。检测字段一致不代表所有网站都会接受。

未签名Windows ARM64/x64安装包，浏览器内核按需下载，在线升级保留环境和登录数据；暂无macOS/Linux原生安装包。
