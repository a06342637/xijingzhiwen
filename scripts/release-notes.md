栖境 0.1.15

## 先看这里：你的电脑下载哪个？

| 你的电脑 | 应下载的安装包 |
| --- | --- |
| Windows 10/11，Intel 酷睿或 AMD 锐龙等常见电脑 | **Qijing-0.1.15-x64-Setup.exe** |
| Windows 10/11 ARM 电脑，例如骁龙 Snapdragon、Surface Pro X | **Qijing-0.1.15-arm64-Setup.exe** |
| 苹果 Mac，M1/M2/M3/M4 等 Apple 芯片 | **目前没有 macOS 安装包，不能使用上面的 Windows .exe** |
| 苹果 Mac，Intel 芯片，正在运行 macOS | **目前没有 macOS 安装包** |
| Linux 电脑 | **目前没有 Linux 安装包** |

Windows 不确定架构：打开“设置 → 系统 → 关于 → 系统类型”。显示“基于 x64 的处理器”选 x64；显示“基于 ARM 的处理器”选 ARM64。

**软件中的 Windows / macOS / Linux 是浏览器身份模拟选项，不代表提供这些系统的原生软件。Apple 芯片同样使用 ARM 架构，但 Windows ARM64 安装包不能安装到 macOS。**

普通用户只下载对应的 **Setup.exe**。`.yml` 和 `.blockmap` 是软件在线更新用的文件，`SHA256SUMS` 是校验清单，都不用安装。浏览器内核在软件内按需下载。

## 本版更新

- **新建弹窗从顶部打开**：取消名称框自动聚焦造成的跳滚，复开回到最上方。
- **紧凑代理输入**：保留整条粘贴内容，自动识别并测试；不再展开代理名称、协议、主机、端口、用户名、密码和绕过字段，也不再显示「解析并填入」。支持带协议的 HTTP/HTTPS/SOCKS5 地址，格式错误会阻止保存。
- **布局顺序**：随机指纹 → 代理 → 创建数量与基本资料 → 浏览器引擎及硬件配置。
- **广泛随机指纹**：随机按钮增加系统、兼容硬件、屏幕/DPR、窗口/视口、语言/时区、显示/输入偏好、支持的图形/音频/媒体和存储参数变化；批量两个及以上每个独立随机并生成新种子。
- **代理保持不变**：随机不改变代理或 WebRTC 网络策略；已保存认证不以明文回填，修改主机时可以保留原认证。开启出口匹配后语言/时区仍按真实出口覆盖。
- 112 项回归测试通过；保留此前回收站、并行内核下载、中文首页及 Python 组件修复。升级保留环境和登录数据，浏览器内核仍按需下载。

## 随机与兼容范围

所选浏览器引擎和设备类型保持，避免与绑定内核冲突；Firefox/移动环境只随机当前支持的参数。真实 IP、外部路径、扩展和服务地址不凭空生成，实验及降低沙箱保护项仍关闭。更大随机度不等于更隐蔽，不保证匿名或检测站满分；显卡名称不会替换真实 GPU。

旧环境不会因升级自动改写指纹；只有点击随机或新建批量时应用上述生成逻辑。已有代理、回收站与启动网址保留。未签名 Windows 安装包，暂无 macOS/Linux 原生安装包。
