栖境 0.1.19

## 先看这里：你的电脑下载哪个？

| 你的电脑 | 应下载的安装包 |
| --- | --- |
| Windows 10/11，Intel 酷睿或 AMD 锐龙等常见电脑 | **Qijing-0.1.19-x64-Setup.exe** |
| Windows 10/11 ARM 电脑，例如骁龙 Snapdragon、Surface Pro X | **Qijing-0.1.19-arm64-Setup.exe** |
| 苹果 Mac，M1/M2/M3/M4 等 Apple 芯片 | **目前没有 macOS 安装包，不能使用上面的 Windows .exe** |
| 苹果 Mac，Intel 芯片，正在运行 macOS | **目前没有 macOS 安装包** |
| Linux 电脑 | **目前没有 Linux 安装包** |

Windows 不确定架构：打开“设置 → 系统 → 关于 → 系统类型”。显示“基于 x64 的处理器”选 x64；显示“基于 ARM 的处理器”选 ARM64。

**软件中的 Windows / macOS / Linux 是浏览器身份模拟选项，不代表提供这些系统的原生软件。Apple 芯片同样使用 ARM 架构，但 Windows ARM64 安装包不能安装到 macOS。**

普通用户只下载对应的 **Setup.exe**。`.yml` 和 `.blockmap` 是软件在线更新用的文件，`SHA256SUMS` 是校验清单，都不用安装。浏览器内核在软件内按需下载。

## 本版更新

- **随机指纹也随机名称**：点击随机自动填写环境名称，再点一次更换；批量每个名称和指纹独立生成，代理沿用。单个环境可随机后手动修改名称。
- **指纹平铺**：新建环境前增加窗口管理入口，勾选已打开环境可排列到当前桌面的指定显示器；支持列表/表格选择和预览。
- **排列方式**：自动1–4个左右等分，更多自动分行；另有左右、上下、网格，网格列数与窗口间距可调。
- 只移动栖境启动的浏览器主窗口，保留未选窗口；最小化恢复，关闭或其他虚拟桌面窗口跳过。使用可用工作区避开任务栏。
- 固定视口不随外层平铺修改；窗口太多受浏览器最小尺寸限制，实际尺寸差异会提示。126项测试通过，保留Google搜索、时间列、书签、扩展和在线更新。

未签名Windows ARM64/x64安装包，浏览器内核按需下载，在线升级保留环境和登录数据；暂无macOS/Linux原生安装包。
