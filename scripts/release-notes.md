栖境 0.1.24

## 先看这里：你的电脑下载哪个？

| 你的电脑 | 应下载的安装包 |
| --- | --- |
| Windows 10/11，Intel 酷睿或 AMD 锐龙等常见电脑 | **Qijing-0.1.24-x64-Setup.exe** |
| Windows 10/11 ARM 电脑，例如骁龙 Snapdragon、Surface Pro X | **Qijing-0.1.24-arm64-Setup.exe** |
| 苹果 Mac，M1/M2/M3/M4 等 Apple 芯片 | **目前没有 macOS 安装包，不能使用上面的 Windows .exe** |
| 苹果 Mac，Intel 芯片，正在运行 macOS | **目前没有 macOS 安装包** |
| Linux 电脑 | **目前没有 Linux 安装包** |

Windows 不确定架构：打开“设置 → 系统 → 关于 → 系统类型”。显示“基于 x64 的处理器”选 x64；显示“基于 ARM 的处理器”选 ARM64。

**软件中的 Windows / macOS / Linux 是浏览器身份模拟选项，不代表提供这些系统的原生软件。Apple 芯片同样使用 ARM 架构，但 Windows ARM64 安装包不能安装到 macOS。**

普通用户只下载对应的 **Setup.exe**。`.yml` 和 `.blockmap` 是软件在线更新用的文件，`SHA256SUMS` 是校验清单，都不用安装。浏览器内核在软件内按需下载。

## 本版更新

- **恢复普通删除到回收站**：环境菜单与批量删除改为移入回收站，保留三天，可恢复。回收站彻底删除/清空及 API delete 仍用于永久清理。

- **一键清空回收站**：在“返回环境”左侧新增按钮，确认后清理全部遗留指纹配置及软件管理的数据，失败项保留供重试。
- **批量代理顺序绑定**：支持多行粘贴，第1行对应第1个环境；只建1个取首行，行数不足复用最后一行。输入框显示三行，粘贴仅识别，点击才测试。
- **代理原文与运行中切换**：原始代理文本加密保存，编辑保持粘贴格式。运行中保存自动重启此环境，切换代理并保留浏览器数据，共用代理自动另存；页面未保存内容可能丢失。
- **时间随机名称**：随机指纹与批量创建使用“四位随机英文字母/数字＋本机日期时间”，精确到秒，例如 `aB3x-20261106-143025`，同批名称独立。
- **本地 API**：入口在诊断中心下方，可生成/复制/重置加密保存的 API Key、启停本地服务与配置端口。支持创建、查询、修改、随机指纹、指定参数、浏览器启停和永久删除。Chromium 返回 CDP 地址，Firefox 与 Chromium 均可通过 HTTP 控制标签页、填写和点击。参考 AdsPower 常用 v1 接口，具体支持范围见软件接口页和仓库 LOCAL_API.md。
- **配置与数据保护**：API 遵循高级功能开关，拒绝未开启或冲突参数；运行中不能修改或删除环境。只监听本机并校验 Bearer Key；端口冲突恢复原服务。
- **验证**：152项测试及构建通过，ARM64/x64安装包各13项管理检查通过，两引擎真实API生命周期、Chromium CDP和运行中代理切换通过。

未签名Windows ARM64/x64安装包，浏览器内核按需下载，在线升级保留环境和登录数据；暂无macOS/Linux原生安装包。
